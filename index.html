30秒でわかる全体像

``` [Guest] ── プレイ3時間 + 参加1日 で自分で昇格 ／ 48時間で強制 ──▶ [member]

[member] になるとできること ├─ 既存の組織に参加申請する └─ 普通組織を設立（10,000EUR・個人払い） ├─ member 3人 + ビーコン ─▶ 都市組織（領土が持てる） │ ※足りなくても [臨時] で昇格可。7日で満たせないと解体 │ └─ member 5人 + 領土9チャンク ─▶ 国家組織 └─ 都市組織・国家組織の傘下に入る ```

  • お金の単位は EUR。初参加で 5,000EUR がもらえます。
  • 組織のお金は個人の財布とは別の「金庫」です。
  • /sethome で帰る場所を作れます（設定も移動もその場で15秒）。
  • 誘われて来たなら /inv <相手のMCID>（[Guest] のあいだ・1回だけ）。

1. ランク（[Guest] ／ [member]）

この章の要点

  • 階級は [Guest] と [member] の2つ。全員が [Guest] から始まります。
  • [Guest] は攻撃されず、死んでも持ち物を失いません。ただし組織を作れません。
  • プレイ時間3時間 かつ 参加1日で自分で [member] へ上がれます。プレイ時間48時間で自動昇格です。
  • ⚠ [member] から [Guest] へは戻れません。[Guest_war] は参戦中だけの一時的な状態です。
  • 数値は初期設定です。実際の値はゲーム内の GUI を見てください。

名前の前に階級タグが付き、TAB リスト・頭の上・チャット・表示名に出ます。既定は [Guest]（灰色）／[member]（緑色）／[Guest_war]（濃い水色）です。

1-1. [Guest] の間の制限

項目 [Guest] の状態 効く範囲
死亡時のアイテム・経験値 ロストしない 全ワールド
プレイヤーへの攻撃・被攻撃 どちらも不可（[Guest] 同士も） 全ワールド
禁止アイテム・エンドクリスタル 持てない・使えない 対象ワールドだけ

対象ワールドの既定は world ／ world_nether ／ world_the_end。ここに無いワールドでは [Guest] でも禁止アイテムを扱えます。

  • 止まるのはプレイヤーが原因の直接攻撃だけです（矢・火の点いた TNT・迫撃砲の弾・ドローンの兵装は撃った人まで辿ります）。MOB・落下・炎・溺死と、自分で自分に与える分は通常どおりです。ログアウト中の死体（NPC）にも同じ保護が効きます。
  • ⚠ 自爆ベスト・自爆滑空ベストを着ての死亡だけは、階級に関わらず持ち物を全部失います。

禁止アイテム（既定6種）: TNT ／ 火打ち石と打ち金 ／ ファイヤーチャージ ／ 溶岩バケツ ／ 溶岩 ／ TNTトロッコ

操作 [Guest]
使う・設置する・拾う できない
インベントリの中で動かす できない（Q キーか画面の外へ捨てるのだけ可）
バケツで汲む・空ける できない（溶岩をすくえません）
持ったまま対象ワールドへ入る 足元へ落とされます

⚠ 自動ドロップはワールド移動・ログイン・リスポーンで走り、防具・左手・カーソルの分も対象です。落ちた物は自分で拾い直せません。ログイン時の削除は既定で無効。ソニックブームとウィザーヘッドランチャーは見た目が同じでも使えます。

初回参加ボーナス 5,000EUR は階級と無関係で、まだ受け取っていない人に配られます。

組織との関係

  • 組織を設立できません（都市組織・国家組織への昇格を実行するのも [member] が必要）
  • 参加はでき、リーダー・副リーダーにもなれます。ただし都市組織「[member] 3人」／国家組織「[member] 5人」の条件に [Guest] は数えません
  • 義勇兵になれません（普通組織が義勇兵として参戦しても巻き込まれません）

1-2. [member] への昇格

プレイ時間 参加日数 状態
3時間 未満 — [Guest] 固定。 まだ [member] になれません
3時間 以上 1日 以上 いつでも自分で [member] へ上がれます
48時間 以上 見ません 自動的に [member]

「参加日数」はログインした日付の数で、1日に何時間遊んでも1日です（境目は UTC+9）。3時間を同じ日に満たせば、その日に達成できます。

上がる方法 確認画面
/member（/rankup /memberup）で状態表示 → /member confirm 出ません（即確定）
/eur の「[member] になる」ボタン（条件達成中のみ表示） 出ます
/eur →「自分の情報」を右クリック（Q キーも可） 出ます

⚠ 上がると取り消せません

得るもの 失うもの
組織を設立できる 攻撃されるようになる
禁止アイテムを扱える 死亡時に持ち物と経験値を失う
都市組織・国家組織の人数に数えられる —

[Guest] には戻れません。 装備が整うまで [Guest] のままで構いません。

上がれない理由と不足分は /playerinfo（/pi /pinfo）か /member に出ます。

  • 条件を満たすと参加の3秒後に1回、その後30分ごとに案内が出ます（昇格すると止まります）
  • 記録と自動昇格の判定は 1分ごと。1回の判定で30分を超える間隔（サーバー停止など）は加算されません
  • 昇格すると既定で全体にアナウンスされ、自分を招待した人のチケット集計も進みます

1-3. [Guest_war]（戦争中の例外）

[Guest] のまま戦争に参戦している間はタグが [Guest_war] になり、1-1 の制限がすべて外れます。攻撃でき、攻撃され、禁止アイテムとエンドクリスタルを扱え、⚠ 死ぬと持ち物と経験値を失います。

所属 [Guest_war] になる？
参戦中の都市組織・国家組織（傘下を含む）の構成員 なる
「戦争参加」を ON にした普通組織の構成員 なる（敵陣営にも所属しているとならない）
参戦設定が OFF の普通組織にしか居ない／義勇兵として参戦した組織に居る ならない（[Guest] は義勇兵に数えません）
  • 戦争準備中から適用され、終戦すると [Guest] に戻ります。判定は1秒ごとで、そのつど本人へ通知されます
  • 状態はオフラインで消えるため、再ログイン後にもう一度「参戦した」通知が出ます
  • /member と /playerinfo は [Guest_war] と出ますが、/eur の「自分の情報」だけは [Guest] のままです

1-4. 管理者による階級の操作

  • 階級を固定できます。固定中は /member も昇格ボタンも使えず、組織も設立できません（理由は設立ボタンに出ます）
  • 不足分を補って [member] にする操作もあります。この場合は本人への通知も全体アナウンスも出ません。プレイ時間・参加日数だけの加算もでき、/playerinfo の数値が増えます

1-5. 昇格チケットで一気に上がる

昇格チケット（既定は名札）をメインハンドで右クリックすると、[Guest] と [Guest_war] はその場で [member] になります。不足分のプレイ時間と参加日数が実際に足され、管理者の階級の固定も解除されます。⚠ 取り消せません。 入手方法は 12-4. 招待と inv ポイント を見てください。

  • 組織は普通・都市・国家の3種類。この章は3つに共通するルールです。
  • 参加は申請して受理してもらいます。同じ種別の組織には1つしか入れません。
  • 権限は29個。すべて足し算で、「拒否」による引き算はありません。
  • 毎月1日に金庫から維持費が引かれ、滞納が7日続くと解体されます。

2-2. 参加と脱退

/eur →「組織一覧」→ 入りたい組織 →「参加申請を送る」。 参加申請の処理 権限を持つ人が受理すると加入です。

参加できない条件 説明
既にその組織に居る —
その組織から追放されている 種別・残り期限・理由がメッセージに出ます
運営公式組織に所属している 他のどの組織にも入れません（普通組織も含む）
同じ種別の組織に所属している 国家1つ・都市1つ・普通組織1つまで
構成員の上限に達している 既定は無制限。運営公式組織には上限なし
別の国家 / 別の都市に所属している 都市・国家に入るときだけ。普通組織は関係なし

  • 戦争中（開戦後）は受理できません。戦争準備中は受理できます。 GUI には準備中も「戦争中は受理できません」と出ますが、表示だけが厳しめです。

  • 都市・国家へ受理されると、上位組織すべてにも自動で加入します。 普通組織は自動加入しません。

  • 運営公式組織へは申請できません。組織メニューからその場で加入します。
  • 同時に出せる申請は1つだけ。取り消しは組織メニューの「参加申請を取り消す」から。
  • 却下されると理由がチャットで届きます（組織側が「なし」を選んだときは理由なし）。
  • 申請はタイトルと音でも知らせます。受け取るかは /eur →「通知設定」。自組織の権限で見ている人は 既定 ON、上位組織の権限で傘下を見ている人は既定 OFF です。

脱退（組織メニュー →「組織を脱退」。確認画面が出ます）

2-3. 役職と29の権限

役職の表示は リーダー / 副リーダー / ロール名（兼任なら / 区切り）/ 権限付き構成員 / 構成員 / 上位リーダー(組織名) / 上位権限者(組織名) の7種類です。

権限は足し算です。 基本権限・副リーダー既定・ロール全部・個別権限・上位組織の分を足します。 引き算はなく、どこか1つで許可されていれば使えます。リーダーは常に全29権限です。 上位組織の権限は下に効きます → 8-2. 傘下に入るとどうなるか

権限の配り方は4種類

種類 中身 触るのに必要な権限

副リーダー既定 副リーダー全員に適用 任免＝役職と権限の管理 / 編集＝権限の編集

  • 役職と権限の管理 と 権限の編集 を他人へ与えられるのはリーダー同格だけです。上の4種類のどこでも 同じで、この2つを含むロールへ人を入れるのもリーダーだけです。

  • どの画面にも「全て許可」「全て拒否」があります。基本権限での「全て許可」は上の2つを飛ばします。

  • ロール名は前後の空白と大文字小文字を無視して重複できません。入れられるのはその組織の構成員だけです。

  • 権限が1つでも入ったロールの削除には 権限の編集 も必要です。改名しても権限と所属は残ります。 削除すると所属者はそのロールぶんの権限だけを失います（組織には残ります）。

  • ロールの操作は 左＝権限 / 右＝所属メンバー / シフト+左＝改名 / シフト+右＝削除（確認あり）。

  • ホワイトリストに登録できるのは構成員だけで、リーダーは登録できません（常に全権限のため）。
  • 副リーダー任免とリーダー変更はどちらも 役職と権限の管理 で、対象は構成員だけです。
  • 傘下組織でリーダー・副リーダーになるには上位組織すべてに所属している必要があります。 足りない分は自動加入を試み、参加条件を満たせなければ任命そのものが失敗します。

2-4. 除名と追放

除名は 構成員の除名、追放は 構成員の追放 で、別々の権限です。

種類 挙動
除名 外すだけ。すぐ再加入できます。記録は残りません
永久追放 外したうえで、以後の参加・受理を恒久的に拒否します
期限付き追放 同上。期限が来ると自動で解除されます
  • どれも理由を聞かれ（なし で省略）、理由は外された本人へ届きます。
  • 追放は 対象・実行者・実行日時・期限・理由 が記録され、組織管理 →「追放リスト」で確認・解除できます。
  • リーダーは除名も追放もできません（自分自身の追放も不可）。副リーダーを外せるのはリーダー同格だけです。
  • 構成員でなくても、名前を指定して先に追放できます。 追放するとその人の参加申請も取り消されます。
  • 日数に 0 を入れても永久追放にはなりません。追放・解除は組織全体と本人へ通知されます。

2-8. 維持費（毎月1日）と [新興組織]

「年月が変わって最初の見回り」で1回だけ課金されるので、サーバーが1日に落ちていても取りこぼしません。 設立した月は課金済み扱いで、最初の維持費は翌月1日です。

種別 最低維持費 チャンク維持費
普通組織 1,000EUR —
都市組織 3,000EUR （固有領土チャンク数 − 1）× 50EUR
国家組織 5,000EUR （固有領土チャンク数 − 1）× 50EUR

中立組織（とその傘下）は上の金額が2倍です。 運営公式組織は 0（滞納も起きません）。[占領中] の組織はチャンク維持費だけが 0 になり、 最低維持費は掛かり続けます（占領された領土がどちらの陣営の領土でもなくなるため）。

金庫が足りなかったら — 最低維持費が優先して払われ、残りは種類ごとに別々の滞納になります。

滞納の種類 猶予 超えるとどうなる
最低維持費 7日 ⚠ 即刻解体
チャンク維持費 7日 外側のチャンクからランダムに領有抹消（全体アナウンスあり）
  • 滞納中は組織メニューと金庫 GUI に滞納額が出ます。見つけたらすぐ入金してください。
  • 金庫にお金が入れば次の見回りで自動的に回収されます（最低維持費が先、チャンク維持費はそのあと）。
  • 領有抹消は滞納額ぶんだけ剥がします。中央区は対象外で、領土は最低1チャンク残ります。
  • 戦争準備中・戦争中は課金そのものが保留され、終戦した直後に保留分がまとめて引かれます。 払えなければそこから最低維持費の滞納が始まります。保留の上限は14日です。

[新興組織] の保護 — 設立すると付き、設立した日の午前0時から7日間、 宣戦布告を受けず、自分からも布告できません（例: 8月13日15時に設立 → 8月20日午前0時まで）。

都市組織へ昇格すると付き直します（設立時の保護が切れていても改めて与えられます）。

昇格のしかた 保護の期限
[臨時] として昇格（条件が足りない） [臨時] と同じ期限。2つは必ず同時に切れます
条件を満たしての昇格 7日（設立時と同じ数え方）

付き直した保護は有料延長できません。元の保護のほうが長ければ短くはなりません。 保護の期限を設定し直すと、自主解除の予約も一緒に消えます。

有料で最大4週間まで延ばせます（組織管理 → 外交方針。要 外交方針 権限）

延長 費用 保護の通算
1回目 5,000EUR 2週間
2回目 10,000EUR 3週間

リーダーは自分で外せます（組織管理 → 外交方針 →「[新興組織] の自主解除」）

項目 内容

取り消し 外れるまではいつでも取り消せます（もう一度押すだけ）

⚠ 延長に払ったお金は戻りません。 次の場合は72時間を待たずに即座に外れます。 自分から宣戦布告した / 参戦要求が承認された / 中立組織になった / 他組織の傘下に入った（編入・移籍とも）。

占領されるとどうなるか

[占領中] が付くだけで、所属・金庫・構成員・領土はそのままです。 領土はどちらの陣営にも数えず、チャンク維持費も 0 になります。 ただし最低維持費 3,000EUR は掛かり続けます。 [占領中] の間は中央区を変更できず、傘下編入の対象にもできません。 奪還できるのは対象組織のツリー（上位・傘下を含む）の構成員だけで、何度でも取り合えます。 同じチームでも、別ツリーの組織は奪還できません。

⚠ [占領中] のまま終戦すると、占領した組織へ併合されます。 相手が国家以外なら都市は消滅し、金庫の全額が相手へ移ります（傘下組織は独立）。 併合では、リーダー・副リーダー・ホワイトリストが全員一般構成員へ落ちます。

6-6. 国家崩壊

爆発による地形破壊

対象は TNT・クリーパー・エンドクリスタル・ベッド・リスポーンアンカーなどで、ブロック1つずつ判定します。

  • 爆発そのものは ON / OFF に関わらず起きます（音・演出・ダメージは別設定）。
  • 領土の外は対象外です。境界をまたぐ爆発では、内側のブロックだけが守られます。
  • 中央区・首都のビーコン・土台・組織色ガラスは、設定にも戦争にも関係なく壊れません。
  • 迫撃砲の弾も既定ではこの設定に従います（サーバー設定で貫くようにもできます）。

爆発物によるMOBへのダメージ

プレイヤーへの爆発ダメージと、ログアウト中の死体は対象外です。未領有地でも働きません。

外部からのTNT / ファイヤーチャージからの保護

外で着火・発射され、領土内へ入ってきた TNT と火の玉を消します。次のものは消しません。

  • 内側から外へ出ていくもの（自分の砲台は使えます）
  • 同じ陣営（上位組織・傘下組織）の領土から来たもの
  • ブレイズが撃った火球／領土の中で着火して中で爆発するTNT

消える瞬間に小さな爆発のパーティクルと爆発音が出ますが、実際の爆発は起きません（ブロックも動物も無傷）。 どの組織も ON にしていなければ追跡すらしないので、設定を変えた直後は最大5秒遅れます。 チャンクが未ロードで見失っても60秒は追跡を続けます。

襲撃からの保護

襲撃の予感を持った相手が領土に入ると、予感を取り上げ、 代わりに吐き気・空腹II・毒II・盲目・鈍足III を30秒付け、金床の合成音を鳴らします。

  • 取り上げるのは襲撃の予感だけです。不吉な予感を持ったまま歩いているぶんには何も起きません（試練の予感も対象外）。 不吉な予感は村に入った瞬間に襲撃の予感へ変わり、そこから襲撃が始まるので、その一手前で止めています。
  • 対象外は、領有者と同じ陣営（上位・傘下）の構成員と、未領有地です。
  • 予感を付けられた瞬間は即座、持ったまま入ってきた場合は1秒以内に反応します。
  • 同じ相手への罰は1秒に1回までです。
  • 村人など予感を持った MOB にも効きますが、メッセージは出ません。

8-6. 外交方針 — 先制攻撃の禁止

項目 既定

他組織の領土内 適用します（設定で未領有地のみにもできます）
自分の系列の領土内 適用外（領土権限の PVP で決まります）
判定 攻撃した人が所属するすべての組織とその上位組織のどれかが ON なら適用
ブロック時 禁止元の組織名つきの警告がチャット（1.5秒に1回まで）とアクションバーに出ます

  • ⚠ 一度 OFF にすると継続日数が0に戻り、中立組織の条件を数え直します。
  • ログアウト中の死体（NPC）への攻撃も、本人への攻撃として扱われます。
  • 中立の間は OFF にできません。運営公式組織は自動で ON です。

8-7. 外交方針 — 中立組織

維持費が高くなる代わりに、宣戦布告を受けにくくなる立場です。設定できるのは系列の最上位だけで、効果は傘下すべてに及びます。タグ [中立] は傘下組織の名前にも付きます。

前提（1つでも欠けるとなれません）: サーバー設定で有効 / 傘下組織でない / まだ中立でない / 戦争準備中・戦争中でない / [臨時] の都市でない。

そのうえで、次の3つを 28日前の午前0時から続けて満たす必要があります。

条件（既定）
先制攻撃の禁止を ON にし続けている
系列全体で戦争に関わっていない
不可侵条約に関わっていない（加盟中・申請中・発効待ちも不可。28日前以降に加盟していないこと）

義勇兵としての参戦は条件に影響しません。なれない理由は外交方針メニューに出ます。[新興組織] の間は3条件なしでなれますが、なった瞬間に保護は失効します。[臨時] の都市はこの例外より先に弾かれます。

維持費 2倍
先制攻撃の禁止 自動で ON。以後 OFF にできません

[新興組織] の保護 その場で失効
不可侵条約 参加できません

中立化には確認画面が出ます。

解除は予約制です。OFF にすると解除予約になり、次の維持費支払日（毎月1日 00:00）に外れます。そこから 解除された日の午前0時 + 14日が猶予期間（元中立組織）です。予約は反映されるまで取り消せます。猶予期間は自分から宣戦布告できず、不可侵条約にも参加できません。布告する側の費用は半額です。サーバー設定で中立が無効にされた場合も次の支払日で解除され、このときだけ猶予期間が付きません。

8-7b. 外交方針 — 義勇兵の方針

傘下組織や構成員が、よその戦争へ義勇兵として参戦することを制御します。/eur → 組織管理 → 義勇兵の方針（権限 外交方針）。クリックのたびに 許可 → 承認制 → 拒否 と巡回します。

対象 何を決めるか 初期値
傘下組織に対して 傘下の普通組織が「組織ごと」参戦することを認めるか 承認制
構成員に対して 構成員が「個人として」参戦することを認めるか 許可

「許可」はそのまま申請でき、「拒否」は申請を弾きます。「承認制」ではあなたの組織の承認が先に要り、承認画面に [自組織の承認] として並びます（左で承認、右で却下）。承認する側に費用はかかりません。

見る場所は申請の単位で違います。組織として申請するときは上位組織すべての「傘下組織に対して」を見ます（自分自身の設定は見ません）。個人として申請するときは所属する組織自身と全上位組織の「構成員に対して」を見ます。いちばん厳しい設定が採用されます。

⚠ 却下しても申請料は戻りません。 金額と申請できる時期は 9-3b. 義勇兵 を見てください。

運営公式組織に指定されると、両方の方針が自動で「拒否」になります。

この章の要点

  • 宣戦布告できるのは都市組織・国家組織だけです。傘下組織はできません。
  • 費用は 10,000EUR ＋ 固有領土チャンク数 × 150EUR。⚠ 取り消せません。
  • 布告から開戦まで約2日。開戦時刻は参戦者全員の投票で決めます。
  • ⚠ 開戦から10分は中央区・首都のビーコンを壊せません。
  • 投票が締め切られた瞬間に参加者が確定し、以後は誰も加われません。
  • 負ければ都市を取られ、条件がそろえば国家が崩壊します。
  • 数値は初期設定です。実際の値はゲーム内の GUI を見てください。

9-2. 戦争準備中

布告すると戦争準備中に入ります。状態は 平時 → 戦争準備中 → 戦争中 → 終戦 と変わります。

布告先 最低準備日数 投票時間
通常の組織 2日 布告から 24時間
中立組織 3日 布告から 48時間

日数は日付の境界で数えます。布告した日が0日目で、0時を回るたびに1日増えます（基準は UTC+9）。開戦日は「布告した日＋最低準備日数」、時刻は投票で決めます。布告した時刻しだいで、開戦までは約40〜68時間です。

あなたか相手のどちらかが既に戦争準備中なら、同じ開戦グループに入ります。 投票を1つ共有してまとめて同時に開戦し、開戦日はグループの中でいちばん早い日です。当事者が増えたときの延長は 9-4 を見てください。

長さ 10秒。領土を出ても切れるまで残る
対象 その戦争の戦闘員（義勇兵を含む）。開戦後は付かない

9-5. チーム

参戦要求で結ばれた組織どうしがチームです。傘下組織は自動で同じチームに入り、同じチームには攻撃も占領もできません。

  • 新しい宣戦布告のたびにチームが増え、同じ開戦グループに3チーム以上できることもあります。
  • 戦果は組織ごとです。占領した都市はビーコンを壊した組織のもので、国家崩壊もその国だけに起きます。
  • 普通組織は既定では巻き込まれません。 組織管理の「上位組織の戦争に参戦」を ON にした普通組織だけが戦闘員になります。中立系列・運営公式組織・上位組織が無い組織は ON にできません。

維持費は戦争が終わってから。 戦争準備中と戦争中は課金が保留され、滞納や人数不足のカウントも止まります（⚠ 保留の上限は14日）。保留分は関わる戦争がすべて終わったあとにまとめて引かれるので、戦費を使い切らないでください → 2-8. 維持費 / 2-9. 自動で解体・消滅する条件

9-7. 都市の占領と [占領中]

敵の都市の中央区ビーコンを壊すと [占領中] が付きます。壊せば必ず占領できる、ではありません。

占領できる条件 内容
戦争の状態 相手の陣営が戦争中で、自分の陣営との間に戦争があること。⚠ 戦争準備中は壊せません
開戦からの経過 ⚠ 開戦から10分は壊せません。 数え始めは戦争状態に入った瞬間（＝投票で決まった開戦時刻）です。残り時間は戦争の BossBar に ビーコン解禁まで と出ます。奪還には掛かりません
壊す人 どこかの組織に所属し、相手の陣営の構成員でも同じチームでもないこと
相手のログイン 相手の陣営の構成員の誰かが1時間以内にログインしていること（義勇兵は数えません）
二重占領 その都市を自分の組織がまだ占領していないこと

占領されたあとの扱いと終戦時の併合は 5-7. 占領される。

  • [占領中] の都市の領土はどちらの陣営の領土にも数えません。奪った都市は自国の「盾」になりません。
  • 奪還できるのは取られた組織の系列の構成員だけです（同じチームの別の組織は不可）。取り合いは何度でもできます。奪還に開戦からの10分は掛かりません（下の猶予は攻める側だけです）。
  • 自爆ベストの起爆でも占領の判定が走ります（爆心から3ブロック以内。条件は同じ）。
  • 占領・奪還・併合・国家崩壊の全体アナウンスは、設定に関係なく必ず流れます。

9-8. 首都を攻める条件

首都ビーコンを壊すと国家が崩壊します。9-7 の条件に加えて次のどちらかが必要です。

条件
条件A 開戦時から減った固有領土が 50%以上（分母は開戦時のチャンク数。開戦時が0チャンクなら成立）
条件B 首都以外の傘下都市が1つも残っていない（[占領中] の都市と、使える中央区を持たない都市は数えません）

固有領土＝本体と傘下都市の自前のチャンクで、[占領中] の組織のぶんは含みません。判定は国ごとで、チームメイトの状況は関係ありません。奪い返して50%を割れば首都はまた守られます。 傘下都市がもともと無い国家は開戦した瞬間から狙われます。崩壊後の扱いは 6. 国家組織 6-6。

開戦した瞬間に、参戦組織と傘下の領土にある保護看板がすべて壊れます。 大事なものは平時のうちに領土の外へ → 16-5. 戦争が起きると保護は消えます

9-10. 戦争中の死亡とリスポーン

対象は戦争中の戦闘員だけです（義勇兵も対象）。戦争準備中は普通に復活します。

項目 内容
復活までの時間 1分。画面が暗転して動けません（無敵ですが何もできません）。水流や乗り物で2ブロック以上動かされると引き戻されます
⚠ 戦闘以外で死ぬと 3分 プレイヤーに倒されたか、死ぬ前30秒のあいだにプレイヤーからのダメージを受けていた場合が「戦闘中の死」で1分です。落下・溶岩・窒息・MOB だけで死んだ場合は3分になります（落ちて死んで前線へ湧き直す、という移動手段にさせないためです）
この1分の間 復活地点を選ぶ画面が出たままになります（下記）
復活する場所 何も選ばなければ、死んだ場所から一番近い自陣営のビーコンの周囲8マス（3×3から中心を除いた8マス）。候補は同じワールドのビーコンだけ
使えるビーコン 同じチームのビーコンも復活先。[占領中] の都市は不可。真上は組織色のガラスなので湧きません
中央区を持たない人 普通組織だけの構成員と義勇兵は、助けに入った陣営の中央区・首都が復活先です
ベッド 無視されます。自陣営のビーコンが無ければ普通のリスポーンです
注意 埋没を見ないので、ブロックの中に湧くことがあります

ビーコンの周囲8マスの、ビーコンと同じ高さとその1つ上には何も置けません（水や溶岩も）。中央区にした時点で片付けられます。

10-1. ショップを作る

/shop create（/eur →「ショップを作る」でも可）のあと収納ブロックを殴ると、 正面に看板が立って完成し、設定GUIが開きます。

条件 内容
ブロック チェスト / トラップチェスト / 樽。ダブルチェストは不可
中身 扱うアイテムを1種類だけ（競売用は何種類でも可）
正面 自分が立っている側が空気
ワールド 既定 world のみ
領土の中 その土地の「使用」権限が必要
作れる数 無制限
作成モード 60秒で自動解除。中止は /shop cancel

既にショップのブロックは選べず、看板を立てられないと作成は取り消されます。

10-2. 看板とモード

看板の4行は 店名（既定 SHOP#登録番号、管理ショップは ★）/ モード（不可なら 取引不可）/ ItemID / 値段・一口 です。 競売中は 開催状態 / 出品物 / 現在価格・残り時間 に変わります。表裏とも同じ内容で、蝋付けのため編集できません。

モード 意味
停止中 取引できない（作成直後はここ）
販売 あなたが売り、客が代金を払う
買取 あなたが買い取り、客が代金を受け取る
競売 収納の中身をまとめて競りにかける（10-8b）

設定GUIで 停止中 → 販売 → 買取 → 競売 → 停止中 の順に切り替わります。 看板は壊せず、その位置に別のブロックも置けず、看板と収納は爆発でも壊れません。消えても1分ごとに作り直されます。

設定GUI 内容
モード切替 停止中 / 販売 / 買取 / 競売

チャット入力の待ち時間は 60秒。管理ショップの設定は eur.shop.admin 保持者だけが操作できます。 /shop settings <番号> は誰でも実行でき、他人の店の資金・在庫・作成者・座標を見られます（ボタンは弾かれます）。

取引GUIの口数ボタンは 1口 / 5口 / 10口 / 64口（「1口」＝一口の取引個数）で、取引できる口数が1以上なら「最大 N口」も出ます。 同じ品を扱う店の検索とチラシ受け取りのボタンもあります。

解体は収納をシフトしながら破壊します。できるのは 作成者 / 管理ホワイトリスト / eur.admin で、開催中の競売があると不可です。 ⚠ ショップ資金は解体した人ではなく作成者へ返却されます。収納の中身は残ります。

10-4. 取引できないとき

看板の2行目が 取引不可 になります。原因が消えると自動で再開します。

理由 場面 直し方
取扱アイテム未設定 全モード 設定GUIで扱う品を決める
停止中 全モード モードを販売か買取にする
値段が0 全モード ⚠ 作成直後は0。値段を決める

在庫切れ（在庫 < 一口） 販売 収納にアイテムを足す
ショップの資金不足 買取 設定GUIの「入金」で資金を入れる
収納が満杯（空き < 一口） 買取 収納を空ける
遠すぎる 客側 6ブロック以内へ行く（10-5）
オークション未設定・未開催など 競売 10-8b を参照

経済プラグインが動いていないときは、お金がからむ操作がすべて失敗します。

10-5. 遠隔からは取引できません

売買できるのは収納から6ブロック以内のときだけで、別ワールドからは不可です。 チラシや一覧から遠くの店を開くと、店名と座標を知らせるだけになります。 離れていると口数ボタンが出ず、画面を開いたまま離れてもボタンを押した時点で弾かれます。

10-6. ショップを探す

/shop または /eur →「ショップ一覧」で一覧GUIが開きます（1ページ21件、開いたまま自動更新）。

機能 内容

安い順・高い順は1個あたりの単価（値段÷一口）で比べ、競売の店は出品物の中身でも引っかかります。 一覧のアイテムは左クリックでチラシ / 右クリックで取引画面。チラシ（紙）にはインベントリの空きが1つ必要で、 店名・座標などが説明欄に載ります。店が消えていると使えません。

10-7. アイテム表示（陳列）

項目 既定
高さ 収納から 1.2 ブロック
更新の間隔 2秒
ショップごとの ON/OFF 設定GUIから

拾えず、吸われず、まとまらず、壊れず落ちず、保存もされません。 サーバー全体で無効なときは、ショップごとの設定に関わらず表示されません。

10-8. 取引履歴と通知

/shop history（全店 / 番号を付けるとその店）、/shop log [件数]（チャット、既定10件）、/eur → 取引履歴 で見られます。 GUIは1ページ28件で、下に 件数 / 売上 / 支出 / 差引 / 保持期間 が出ます。他人の店の履歴は見られません。

  • 履歴は最大 5,000件・30日。店名は取引した時点のものが残ります。
  • 取引が起きると作成者と管理ホワイトリスト全員へ通知が飛びます（本人を除く）。
  • ログインすると不在中の取引がショップごとにまとめて出ます。

10-8b. オークション（競売）

収納の中身をまとめて1つの品として競りにかけ、落札した人が全部受け取ります。 /shop auction のあと出品物を入れた収納を殴り、看板をシフト+クリック →「オークションの設定」へ。 中身は何種類でも構いません。

⚠ 既存のショップをモード切替で競売にしただけでは最低価格も開催時間も0のままで、 看板は「未開催」、理由は「オークションが未設定です」になります。設定GUIで入れてください。 /shop auction で作ったときだけ 最低価格100EUR / 開催24時間 / 開始待ちなし が入ります。

設定項目 範囲
最低価格 1EUR 以上。0だと開始不可
開始までの時間 7日まで
開催時間 1分以上 7日まで。0だと開始不可

日・時間・分は 左クリック +1 / 右クリック（Q キー） -1 / シフトクリックで入力。 設定画面には「出品予定の品」の内訳が出ます。⚠ 開始待ち・開催中は設定を変更できません。

開始と取りやめ

開始は 作成者 / 管理ホワイトリスト / eur.admin が行い、収納が空だとできません。

  • 押した瞬間に収納の中身をすべて引き取ります（あとから入れた物は出品物ではありません）。
  • 預かるので収納を壊されても失われません。看板と一覧のアイコンは代表アイテムに変わります。
  • 開催中は解体もモード変更もできません。 開始は全体に知らされます（設定OFFなら見張っている人だけ）。
  • 取りやめは入札がまだ無ければ開始待ち・開催中どちらでも可。⚠ 入札が入ると不可で、eur.admin だけが強制的に止められます（預かり金は返金）。
  • 取りやめた品は収納へ戻り、入りきらないぶんは受け取り待ちになります。

入札

項目 内容
できる時 開催中だけ。開始待ち・終了後は不可
次に必要な額 現在価格 + 上乗せ（1EUR か 5% の大きい方）
お金 入札時に全額を預かり、上を越されたらすぐ返金
上乗せ 自分が最高額なら差額だけでよい
距離 取引と同じく6ブロック以内
出品者・管理ホワイトリスト 入札不可

入札画面には出品物が並び、「最低額で入札」「金額を指定して入札」、通知 ON/OFF、受け取り、一覧のボタンがあります。

終了と受け取り

  • 入札あり: 最高額の人が全部落札。売上はショップ資金に入り、作成者は「出金」で受け取ります。履歴には「落札された」と残ります。
  • 入札なし: 品は収納へ戻り、チャンク未読込や入りきらないぶんは受け取り待ちです。
  • 終了後は解体もモード変更もでき、もう一度「開始」で再開催できます（入札はリセット）。
  • 店が消えるときは預かり金を返金し、品は受け取り待ちにします。

受け取りは /shop claim、/eur →「オークション」を右クリック、入札画面の「落札品の受け取り」から。 ⚠ インベントリに全部入らないと受け取れません（一部だけは渡しません）。必要な個数とスタック数が出ます。 期限は無く、店が解体されたあとでも受け取れます。ログイン時に未受け取りの知らせが出ます。

通知は 開始・終了＝全員（設定OFFなら見張っている人だけ）、残り5分・残り1分の予告＝見張っている人と出品者・管理ホワイトリスト、返金＝本人です。 入札すると自動で見張りに入ります。ON/OFF は入札画面のベル、既定は /eur →通知設定です。

12-1. home と spawn

/home で移動し、/sethome で今いる場所を登録します。/spawn はスポーン地点へ飛びます。 GUI は /eur → home / spawn からも開けます。コマンドとサブコマンドは 13-1. プレイヤー用コマンド にまとめてあります。/setspawn は運営専用です。

15秒じっと待ちます

項目 内容
待ち時間 15秒（戦争に参戦している間は /home /sethome /spawn と組織ホームが 60秒）

残り秒数はアクションバーに出ます。視点の回転や騎乗の扱いは 2-6. 組織ホーム と同じです。

よその領土のそばには置けません

自分の系列（所属組織とその上位・傘下）以外の組織の領土と、そこから 3チャンク以内には home を置けません。系列内の領土と未領有地には置けます。どこにも所属していない人は、すべての組織の領土が対象です。

  • 判定は移動のたびにも走ります。座標は消えないので、相手が領土を放棄すればまた使えます。
  • 戦争に参戦している間は、移動の判定だけ 16チャンクに広がります（/sethome は3チャンクのまま）。組織ホームは対象外です。

枠は3つ。2つめ以降は home チケット

枠 扱い
1つめ 無料・無期限。引数なしの /home /sethome はこの枠
2つめ・3つめ チケットの契約制。1枚で 14日

チケットを右クリックすると使い道を選べます。「新規に開く」は未契約・期限切れの枠に使い、開いた瞬間から14日です。「契約を延長する」は契約中の枠に 14日足します。減るのは枠を選んだ瞬間だけで、無料枠には使えません。枠を開いたら /sethome 2 で地点の設定が要ります。/home del で座標を消しても、契約（期限）は残ります。

⚠ 契約が切れた枠はリセットされ、座標も消えます。 切れる前に延長してください。

できなくなることの一覧は 9-6. 戦争中にできなくなること、移動と復活は 9-10. 戦争中の死亡とリスポーン にあります。 /tpa とエンダーチェストが使えるのは戦争準備中までで、待ち時間は 15秒のままです。

12-9. 賞金首（Wanted）

特定のプレイヤーに賞金を掛けられます。その人を倒した人が全額を受け取ります。

項目 内容
掛けかた /wanted <プレイヤー> <金額> ／ /eur → 賞金首 → 賞金を掛ける
最低額 1,000EUR。同じ人が何度でも積め、合計が賞金額
お金 掛けた瞬間に所持金から引かれる。⚠ 自分では取り消せない（運営だけが返金付きで消せます）

掛けられない 自分。同じ組織ツリーの相手は倒しても受け取れない（賞金は残る）

  • 確認コマンドは 13-1. プレイヤー用コマンド（/wanted list は高い順に10人まで）。
  • [賞金首] の札が付くのは /wanted list の行と /playerinfo の中だけです。名前・チャット・タブ一覧・頭上には付きません。

12-10. ログアウト中の死体

ログアウトすると、その場所にあなたの死体が 180秒（3分）残ります。

項目 内容
見た目 あなたのスキン・装備のまま立ち、頭上に名前が出る
引き継ぐもの 体力・空腹・ポーション効果・炎・残り息・落下距離・運動量
倒されると 持ち物（防具・オフハンドを含む）と経験値をその場に落とす
再ログイン 無事ならそのまま戻る。倒されていた場合は、ログインした瞬間に持ち物と経験値を失って死亡
出ない場合 クリエイティブ・スペクテイターでのログアウト
  • 死体への攻撃は本人への攻撃として判定されます。領土の PVP 設定・7-4b. 交戦状態・先制攻撃の禁止・[Guest] の保護がそのまま働きます。

  • 窒息と押し合いだけはダメージになりません。日光では燃えませんが、溶岩・炎では燃えます。
  • 死亡メッセージは倒されたその場で普通のプレイヤーと同じ形で流れます（NPC を使えずゾンビで代わりを出す環境では、既定では流れません）。

12-15. オンラインタイムチケット（/ott）

サーバーに居るだけでたまるチケットです。10分に1枚たまり、/ott の画面から枚数を指定してアイテムとして取り出せます。取り出したものは同じ画面から預け直せます。

項目 内容
たまり方 サーバーに居るあいだ 10分ごとに1枚。自動で「預り」に入ります
画面 /ott（/eur → オンラインタイムチケット からも）
取り出す 上の段。1 / 8 / 16 / 32 / 64 のボタン、「ありったけ」、「枚数を指定」（チャットで入力）

  • 取り出したチケットには持ち主の印が付きません。誰が取り出したものでも1スタックにまとまるので、そのまま人に渡せます。
  • 所持枚数ランキングは「預けている枚数」で並びます。 取り出してアイテムにしたぶんは数えません（オフラインの人の持ち物は見られないため）。順位を上げたいときは預けてください。

  • 月間累計は今月ぶんです。月が変わると 0 から数え直しになります（前の月の記録も残っています）。
  • 持ち物がいっぱいのときは入るぶんだけ渡され、残りは預りに残ります。地面には落ちません。
  • サーバーが止まっていた時間や、抜けているあいだは数えません。

13-2. GUI の操作（右クリックが出せないとき）

統合版（Bedrock）とタッチ操作の環境では、GUI の中で右クリックが出せません。 そのままでは「右クリックで削除」のような操作に一切手が届かないので、 アイテムを落とす操作が右クリックの代わりになります。

GUI での操作 代わりになるもの
右クリック Q（アイテムを1個落とす操作）
シフトクリック Ctrl+Q（1スタック落とす操作）
シフト+右クリック Ctrl+Q
  • アイテムは落ちません。 GUI の中のクリックはすべて打ち消しているので、押しても持ち物は減りません。
  • 見ているのは「落とす」という操作そのものです。キーを割り当て直していても、統合版で捨てる操作をしても、同じように効きます。
  • このガイドで GUI の操作として「右クリック」と書いてあるものは、すべて Q でも押せます。 ゲーム内の説明文にも 右クリック / Q と出ます。
  • ⚠ 効くのは GUI の中だけです。ワールドのブロックや、手に持ったアイテムを右クリックする操作は Q では代われません（EURphone・home チケット・紙幣・ルーレット台・迫撃砲など）。

14-1. 階級について

Q. [member] になるにはどれくらいかかりますか プレイ時間3時間 かつ 参加日数1日です。日数はログインした日付の数で、同じ日に3時間遊べばその日に上がれます → 1-2

Q. 条件を満たしたのに member になりません 自分で /member confirm か /eur のボタンで上げます。48時間で自動昇格。⚠ 取り消せません。

Q. [Guest] なのに死んで持ち物を失いました 自爆ベスト2種での死亡と [Guest_war] の間だけは、階級に関わらず全部失います → 17-2

Q. TNT が持てません [Guest] の制限で、対象は既定の3ワールドだけです。外なら持てます → 1-1

Q. [Guest] でも組織に入れますか 入れます。設立だけが member 限定。都市3人・国家5人の頭数に数えず、義勇兵にもなれません。

14-2. 組織について

Q. 組織を設立できません member でない／既に普通組織に所属・設立済み（1人1つ）が大半です。 ⚠ 10,000EUR は金庫ではなく個人の所持金から引かれます → 3-1

Q. 初心者組織から抜けたいのですが 在籍中でも脱退できますが、⚠ 自分から抜けても卒業あつかいで再加入は既定で不可です。 GUI の「在籍中は脱退できません」は古い表示です → 2-11

Q. 金庫から出金できません 権限が無いか、戦争準備中・戦争中です。入金はできます。資金は布告の前に出してください。

Q. 都市に昇格できません。ビーコンは置いたのに ビーコンの6条件と、そのチャンクに立っているかを確かめます → 5-2 人数とビーコンは [臨時] で後回しにできますが、8チャンクの距離は緩みません。

Q. 上位組織のリーダーがうちの組織をいじれます 仕様です。上位のリーダーは傘下でもリーダー同格。金庫・領土・ショップの所有は独立ですが、 ⚠ 上位の出金権限者は傘下の金庫から出せます。

Q. 「役職と権限の管理」と「権限の編集」は何が違いますか 前者は誰をその役職に入れるか、後者は何をできるか。配れるのはリーダーだけです → 2-3

14-3. 領土について

Q. 領土が取得できません 縦横の隣接が要り（斜めは不可）、四方を囲う取得は禁止です。 戦争中は不可、戦争準備中はできます → 7-2

Q. 中央区のチャンクを放棄できません 中央区・首都は放棄できません。移すには「中央区の変更」（20,000EUR / 30日）を使います。

Q. 自分の土地なのに建築できません アクションバーの「設」が赤くないか見てください。区分か個別設定が拒否です → 7-4

Q. PVP 禁止の自分の街なのに攻撃されました 交戦中だからです。殴り合った2人は30秒どこでも撃ち合えます（殴るたび延長）。 無視されるのは PVP 設定だけで、戦争準備中の参戦者には付きません → 7-4b

Q. 街に居る人へ先に殴りかかれますか できません。交戦は攻撃が通ったときだけ始まり、PVP 禁止の領土では最初の1発が弾かれます。 ただし外で始めた喧嘩は、街へ逃げ帰っても追ってこられます。

14-4. 戦争について

Q. 宣戦布告のボタンが押せません 宣戦布告 権限が無い、自分か相手が [新興組織] か [臨時]、自分が傘下・中立・元中立、 終戦から3日のクールタイム中、投票時間が閉じたあと、が大半です → 9-1

Q. 戦争準備中は何ができなくなりますか 領土の取得と、新しい構成員の受理はできます。 止まるのは 出金／領土の放棄／中央区・首都の変更／ 昇格／解散／傘下／領土譲渡／中立化／条約／ホームの設定／リーダーの引き継ぎ → 9-6

Q. 途中から戦争に参加できますか 投票時間が終わった瞬間に参加者が確定し、以後は布告も参戦要求も義勇兵も出せません → 9-4

Q. 義勇兵の申請料は返ってきますか ⚠ 返りません。 却下・取り下げ・24時間の期限切れ・終戦、どれでも同じです。 承認制の上位組織があるときは、その承認の前に引かれます → 9-3b

Q. 都市を占領したのに相手の都市が消えません [占領中] が付くだけで、所属も金庫も構成員もそのまま。終戦まで残って初めて併合されます。 奪還できるのは取られた組織のツリーだけです → 5-7. 占領される

Q. 首都のビーコンが壊せません 条件A（開戦時の固有領土から50%以上減った）か条件B（首都以外に数えられる傘下都市が無い）と、 相手陣営の誰かの1時間以内のログインが要ります → 9-8

  • 同じ条約の国どうしは宣戦布告できません。盟主はいません。
  • 加盟・脱退・解散・追放は、締結国の投票で決めます。
  • 可決は「賛成 > 反対」だけ。定足数はなく1票でも通ります。
  • 施行は可決から3日後。追放だけ即時です。
  • 独断脱退には7日間のペナルティが付きます。
  • 数値は初期設定です。実際の値はゲーム内の GUI を見てください。

入口は /eur → 不可侵条約 です。 作成・申請・発議・投票には 不可侵条約 の権限が要ります。権限は最上位組織で見ます（傘下のリーダーは最上位側でもらわない限り不可）。

15-1. 入れる組織

  • 都市組織・国家組織（普通組織は不可）で、ツリー最上位の組織（傘下は不可）
  • 中立組織でない／元中立組織の猶予期間（14日）中でない
  • 戦争準備中・戦争中でない

この判定は入るときだけです。加盟後に戦争を始めても外れません。 中立とは両立しません。 加盟中・申請中・発効待ちは中立になれず、抜けたあとも28日間なれません。 掛け持ちの数に制限はありません。加盟申請だけは同時に1つです。

15-2. 作る

項目 内容
条約名 24文字まで・重複不可
失効日 必須。1〜60日
作成費用 5,000EUR ＋ 500EUR × 日数（30日で 20,000EUR）
維持費 締結国それぞれ 24時間ごとに 150EUR

費用も維持費も金庫から引かれます。維持費を払えない国はその場で外れます（ペナルティなし）。

⚠ 1カ国から作れますが、1カ国のまま3日たつと消滅します。費用はどの場合も戻りません。

15-3. 入る

  1. GUI から加盟申請（2,500EUR、申請時に引かれます）。その場で「新規加盟」の投票が自動で始まります（締結国側に受理の操作はありません）
  2. 可決の3日後に発効します。発効の瞬間に 15-1 を再判定し、満たさないと不成立です

申請は可決前なら取り消せます。取り消すと加盟の投票も打ち切られます。 申請できないのは、既に締結国／加盟が可決済み／解散が決まった条約／失効した条約／別条約へ申請中のときです。

⚠ 申請費用は、取り消しても否決されても戻りません。 申請中・発効待ちは守られません。 その間に宣戦布告されることがあります。

15-5. 抜ける

ペナルティなしで抜けられる場合: 脱退の投票の可決（3日後に離脱）／維持費の未払い／最上位組織でなくなった／組織の消滅。 追放と独断脱退は即時です。追放は自分に有利、独断脱退は不利に働きます。

ペナルティの倍率（7日間）

種類 元締結国 → 自分 自分 → 元締結国
独断脱退 布告費用 0.5倍 布告費用 3倍

  • 「7日間」は抜けた日の午前0時から7日後の午前0時まで。対象は外れた瞬間の締結国で固定です。
  • あとから加盟した国には効かず、条約が解散しても倍率は残ります。
  • 双方にペナルティがあると掛け算されます（例: 0.5 × 3 = 1.5倍）。
  • 続けて抜けると対象は累積し、種類と期限は後の脱退で上書き。新しく条約に入るとその場で消えます。

15-6. 条約国に宣戦布告したい

そのままでは布告できません。「条約を破棄して宣戦布告」を使うと、相手と共有する条約をすべて破棄して布告します（宣戦布告 と 不可侵条約 の両方の権限が必要／独断脱退あつかい）。 ⚠ 布告できるか先に確かめてから破棄しますが、布告に失敗しても破棄だけ成立し、取り消せません。 参戦要求を承認して条約国の敵側に回ったときも、その条約から自動で独断脱退します（義勇兵での個人参加は対象外）。

  • 守りたいブロックに看板を貼り、1行目に [Private] と書きます。
  • 2〜4行目に使える人を3件まで書けます。
  • 壊せるのは [Private] に書いたプレイヤーと、その領土の権限者だけです。
  • ⚠ 開戦すると参戦組織の領土の保護看板は消え、戻りません。

コマンドも GUI もありません。看板だけで使います。

16-1. 看板の書き方

守りたいブロックの6面（上下も可）のどこかに看板を貼ります。

[Private] Steve [レド]

成功すると ブロックを保護しました。 と出ます。

見出し（日本語も可） 意味
[Private] [プライベート] [所有者] 持ち主。1つの保護に1枚だけ
[More Users] [共有] [追加ユーザー] 使える人を足す。何枚でも

[More Users] だけでは保護になりません。 2行目が空なら自分の名前が入ります（[More Users] でも同じ）。 看板は次の瞬間に書き直され、色と空白は消え、空行は詰まります。 ⚠ [Private] 看板は後から書き直せません。持ち主でも弾かれます。

対象外のブロック、[Private] の重複（書き直しも）、[Private] なしの [More Users]、他人の保護への追加は弾かれ、文字が入りません。

16-2. 守れるもの

種類 例

扉 ドア・トラップドア・フェンスゲート（鉄・銅も）

両開きチェストは看板1枚で両方守れます。 扉は上下2ブロックと真下の土台、どこでも効きます。コンテナは土台では効きません。 ⚠ 土台自体は保護されず、壊されると看板も落ちます。

16-3. 2〜4行目に書けるもの

プレイヤー名 使えます。[Private] の人だけが壊せます
[組織名] その組織と傘下の構成員が使えます。正式名でも略称でも可
[Everyone] 誰でも使えます。壊すのは不可

UUID でも記録するので改名しても効きます。未接続の名前は文字の一致だけで判定します。 [Redstone] [Timer:5] は未実装で効果がありません。「timer」で始まる名前・略称の組織も指定できません。

16-4. 守られる範囲

許可されていない人は、次ができません。

  • 中を開ける・扉を操作する（右クリック）
  • 手で壊す、保護看板を壊す
  • 隣に同じチェストを置いて両開きにする
  • 保護ブロックの6面のどこかにホッパーを置く
  • ホッパーで中を吸い出す（所有者名が完全に同じ保護同士なら通ります）
  • 爆発・延焼・ピストン・エンダーマンやゾンビによる破壊

拒否されると ここは保護されています（所有者: 名前）。 と失敗音が出ます。 保護コンテナへ入れるのと看板の文字の書き換えは誰でもできますが、保護は残ります。 op（eur.lock.bypass）はすべての保護を無視します。 その保護が組織の領土の中にある場合は、領土の権限者も無視できます → 16-5。

16-5. 領土の持ち主は保護を上書きできます

保護が組織の領土の中にあるとき、その領土を持つ組織のリーダーと、 領土内の保護の解除 の権限を持つ人は、他人の保護でも開ける・壊す・ [More Users] を足すことができます。看板に名前が載っている必要はありません。

項目 内容
効く場所 その組織（と傘下）の領土の中だけ。⚠ 未領有地の保護には効きません
できる人 リーダー（常に全権限）／領土内の保護の解除 を持つ人／上位組織で同じ権限を持つ人
初期値 リーダーのみ。副リーダーには入っていません（組織管理 → 役職と権限 で配れます）
できること 開ける・扉を通る／ブロックと保護看板を壊す／[More Users] を足す
できないこと [Private] を2枚にすること（これは持ち主でも不可）

使うと ◯◯ の領土の権限で、他人の保護を開錠しました（所有者: 名前）。 と本人に出ます （アクションバーは毎回、チャットは30秒に1回まで）。相手には通知されません。

⚠ 領土を借りている側から見ると、大家はいつでも中を見られるということです。 他組織の領土にチェストを置くときは、そのつもりで置いてください。

16-6. ⚠ 戦争が起きると保護は消えます

開戦した瞬間、参戦組織と傘下の領土から保護看板が撤去されます。 そのチャンクにあれば他人の看板も [More Users] も消え、ドロップもしません。

  • 終戦しても戻りません。 中身のアイテムは消えません。
  • 撤去は開戦の1回きりです。貼り直せばそのまま効きます。
  • 撤去は少しずつ進み、終わると枚数が組織へ通知されます。

参戦していない組織の領土は影響を受けません。大事なものは領土の外へ移してください。

BlockLocker から移行した場合、以前の [Private] 看板はそのまま効きます。 持ち主は看板ブロック自体にも記録されています。

装甲

APC・IFV・MBT・CAS ヘリは装甲付きです。装甲には次のものしか効かず、 それ以外（機銃・普通の銃・矢・殴る）は弾かれます（火花と音が出ます）。

装甲に効くもの 例
爆発TNT・クリーパー・迫撃砲・地雷・破片弾・ミサイル
火火や溶岩の上に入る・燃える（燃えている間は3倍）
徹甲弾12.7mm・25mm・125mm の徹甲弾
1回で40より大きいダメージ強い銃の直撃など。40ぶんは装甲が受け止めるので、入るのは「ダメージ − 40」です（50 の直撃なら 10）
水没水の底に2ブロック以上沈む

装甲の厚さと貫通

装甲付きの車両には装甲の厚さが、弾には貫通があります。 貫通が装甲の厚さに届かないほど直撃のダメージが小さくなり（(貫通÷装甲)の2乗を掛けます）、 10分の1を下回ると弾かれます。爆発・火・水没は装甲の厚さを見ません。

装甲の厚さ 弾の貫通
MBT 220 / IFV 90 / APC 60 / CAS ヘリ 40（ほかの車両は装甲なし）空対地ミサイル 420 / 対戦車ミサイル 400 / ワイヤー誘導ミサイル 350 / 125mm 徹甲弾 300 / 25mm 徹甲弾 80 / 12.7mm 45 / ロケット弾 40 / 機銃 8

たとえば 25mm 徹甲弾は MBT にはほとんど通らず（1発 45 が約6）、IFV には8割ほど通ります。 12.7mm は MBT には弾かれ、IFV には4分の1ほど通ります（1発 8 が 2）。戦車を止めるには、125mm 砲・ミサイル・爆発・対戦車地雷が要ります。 それでも破片弾よりは徹甲弾のほうが効きます（MBT に 25mm 徹甲弾は約6、25mm 破片弾は4.5）。

ミサイルはタンデム弾頭です。前の装薬が外側を潰すので、装甲の厚さを半分として貫通と比べます。 MBT（厚さ220）はミサイルには 110 の厚さしかないのと同じです。 地上の対戦車ミサイル（固定兵器・IFV のワイヤー誘導）は直撃と爆発で1発 約290——MBT は2発・IFV も2発。 CAS ヘリの空対地ミサイルはそれより弱く1発 約194で、MBT は3発（IFV は2発）かかります。

CAS ヘリにも装甲が付きました（厚さ40）。機銃（7.62mm）は通りませんが、 12.7mm（対空砲・固定12.7mm機関砲。貫通45）と 25mm 徹甲弾はそのまま通ります。 対空砲は耐久も 200 になったので、正面から撃ち合えば対空砲のほうが先にヘリを落とせます（対空砲 約1.25秒／ヘリの 25mm 約1.33秒）。空を追い払うのは対空砲と IFV の 25mm です。

装甲付きの車両の中にいる人は、外からの攻撃・爆発・火を受けません（車両が代わりに受けます）。 車内からは銃を撃てません。APC の上の機銃手や、装甲の無い車両の乗員は体が外に出ているので、撃たれます。 乗っている人は、窒息・落下のダメージを受けません。

煙幕

MBT・IFV・APC は煙幕を張れます。煙は大きく広がり、煙の向こうは見えません（粒子を減らす設定にしても見えません）。 車両や人がまるごと隠れます。発煙弾の煙は40秒、エンジンの煙は20秒ほどで消えます。

煙 使う場所 内容
発煙弾（40mm）射手・運転手のホットバー砲塔の向きへ扇形に6発撃ち、25ブロックほど先に幅50ブロックほどの煙の壁を作ります。2回まで込めておけ、1回撃つと3秒あけます。時間では戻りません——「状態・燃料・弾・席」の画面の発煙弾の枠から火薬 2個で1回ぶん補給します
エンジンの煙運転手のホットバー右クリックを押している間、車体の後ろから煙を出し続けます（左クリック・タップ・Q で出す／止めるの切り替え）。続けて出せるのは20秒ぶんで、出していない間に戻ります（空から満タンまで40秒。使い切ると4分の1戻るまで出せません）。出している間は燃料を多く使います

壊れる

耐久が半分を切ると煙、4分の1を切ると火の粉が出ます。 耐久が 0 になると爆発して消え、乗っていた人は外へ放り出されてダメージを受けます。周りにも爆風が届きます。キットは戻りません。

領土の中の車両を攻撃するには、人が乗っていれば PVP、乗っていなければ MOB 攻撃の権限が要ります （乗っている人と交戦中なら通ります）。ゲストは、人が乗っている車両を攻撃できません。

修理

車両の画面の「修理する」で、鉄インゴットを1個ずつ使って直します （1個で最大耐久の5%・1秒に1個。名前の付いた鉄インゴットは使いません）。 修理の間は車両のそばを離れないでください。車両が攻撃を受けると中断します。

乗ったまま・燃えている間（水で消せます）・車両が攻撃を受けてから・撃ってから30秒の間・ 自分が交戦状態の間は、修理できません。

誘導ミサイル

撃ったあとも、射手が見ている先へ曲がって飛びます（狙っている点が赤く光ります）。 射手が席を離れる・狙っている先が見えなくなる（間に何かが入る・煙幕に隠れる）と誘導を失い、そのまま真っすぐ飛びます。 600ブロック飛ぶか、21秒たつと爆発します。15ブロック以内で当たった弾は爆発しません（信管）。
